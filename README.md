# PARA LLEVAR Outreach

A separate editorial sales workspace for PARA LLEVAR.

| --- | --- | --- |
| PARA LLEVAR magazine | $14 | $26 |

Advertising media kit: one full page $800, two full-page ads $1,600, a two-page spread $2,000, contributor-page thank you $200, and editor's-letter brand integration $400.

## First working prototype
- Responsive black-and-white editorial interface
- Dashboard, prospect pipeline, and three separate lead categories
- Wholesale, Advertising, Retail, Inbox/Follow-ups, and Pricing pages
- Manual add/edit of business records with status, dates and notes
- Category-specific editable sales messages
- Manual recording of sent emails and reminders due three days later

## Important: prototype limitations
This is an initial front-end MVP, not yet the secure production clone of Creative Strategies. Data is saved only in the current browser using localStorage and is not shared between staff or devices. There is currently no login, hosted lead database, AI research, integrated email sending, inbox synchronization, or automated email follow-up. The “Record Sent” button only logs an action; it does not send an email. Please do not enter sensitive client data at this stage.

## Production roadmap
1. Separate Cloudflare Workers backend and D1 database
2. Owner and caller permissions and shared database
3. Duplicate detection, audit history, and reliable activity tracking
4. PARA LLEVAR-branded email sending and Gmail reply matching
5. AI-assisted wholesale, retail, and advertising prospecting, plus approved personalized outreach
6. Reviewable scheduled follow-ups that stop upon reply
7. Sales reporting by category and media-kit proposal workflow

Current media kit claims and advertising inventory should be confirmed before offering them to prospects.
